# MyTaskApp — Decisões de Arquitetura (movido)

Os ADRs que ficavam aqui agora estão um por arquivo, com o mesmo número
(`ADR-NNN`) e o mesmo texto:

- índice, com status, categoria e palavras-chave: [`architecture/README.md`](architecture/README.md);
- cada decisão: `architecture/decisions/NNN-*.md`;
- stack, camadas e as notas avulsas que ficavam entre os ADRs (nomenclatura,
  edição atômica, persistência, lembretes): [`architecture/overview.md`](architecture/overview.md);
- "Teste de UI: só onde paga": [`testing/README.md`](testing/README.md#teste-de-ui-só-onde-paga).

Não acrescente ADRs neste arquivo. Ele só existe para os links antigos
continuarem funcionando. O texto completo de antes da divisão continua no
histórico do Git (`git log -- docs/ARCHITECTURE.md`).
